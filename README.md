# Wallah Classes – Automated Customer Enquiry Management System

## About the Project
This project automates student course enquiries using n8n, Google Sheets, and Gmail. It collects student information through an online form, stores enquiries in a spreadsheet, and sends automatic email notifications.

## Technologies Used
- **n8n:** Workflow automation
- **Google Sheets:** Enquiry data storage
- **Gmail:** Automated email communication

## Features
- Online student enquiry form
- Automatic saving of enquiry details
- Unique enquiry ID generation
- Student confirmation email
- Admin notification email

## How It Works
1. A student submits the enquiry form.
2. n8n processes the submission.
3. Student details are saved to Google Sheets.
4. A confirmation email is sent to the student.
5. An admin notification email is sent.
